TASK BREAKDOWN:
================================================================================

1. DATA LOADING & EXPLORATION
   - Load transactions.parquet using pandas/pyarrow
   - Perform exploratory data analysis (EDA):
     * Display dataset shape, columns, dtypes
     * Show basic statistics (mean, std, min, max, quartiles)
     * Identify missing values and data distribution
     * Create visualizations (histograms, boxplots, correlation matrix)

2. DATA PREPROCESSING
   - Handle missing values (imputation strategies)
   - Remove or handle outliers if necessary
   - Perform feature scaling/normalization (StandardScaler, MinMaxScaler)
   - Handle categorical variables (encoding if present)
   - Perform feature engineering if beneficial

3. DIMENSIONALITY REDUCTION (Optional but Recommended)
   - Apply PCA (Principal Component Analysis)
   - Apply t-SNE or UMAP for visualization
   - Analyze explained variance
   - Visualize reduced dimensions

4. UNSUPERVISED LEARNING MODELS - SELECT AND IMPLEMENT:
   
   RECOMMENDED MODELS (choose 2-3):
   
   A) K-Means Clustering:
      - Determine optimal clusters using elbow method or silhouette score
      - Fit model with optimal k
      - Analyze cluster characteristics
      - Visualize clusters in 2D/3D space
   
   B) Hierarchical Clustering:
      - Create dendrograms
      - Compare different linkage methods
      - Analyze cluster structure
   
   C) DBSCAN Clustering:
      - Find optimal epsilon and min_samples
      - Identify core points and noise points
      - Analyze cluster density
   
   D) Gaussian Mixture Models (GMM):
      - Fit with different numbers of components
      - Compare with BIC/AIC
      - Analyze component weights and covariances
   
   E) Isolation Forest (Anomaly Detection):
      - Detect anomalies in transaction data
      - Visualize anomalies
      - Analyze anomaly characteristics

5. MODEL EVALUATION & VALIDATION
   - Calculate evaluation metrics:
     * Silhouette Score
     * Davies-Bouldin Index
     * Calinski-Harabasz Index
     * Inertia (for K-Means)
   - Create comparison tables
   - Visualize metrics for different model parameters

6. RESULTS INTERPRETATION
   - Analyze what patterns/clusters were discovered
   - Interpret business meaning of clusters/patterns
   - Create summary statistics for each cluster
   - Generate visualizations showing insights

7. ABSTRACT GENERATION
   Write a comprehensive academic abstract (200-300 words) including:
   
   - **Background**: Brief context about transaction data analysis
   - **Objective**: State the unsupervised learning approach
   - **Methodology**: 
     * Data preprocessing steps
     * Models selected and why
     * Evaluation metrics used
   - **Key Findings**:
     * Optimal parameters found
     * Clusters/patterns discovered
     * Key metrics and scores
   - **Conclusions**: Business implications and insights
   - **Future Work**: Recommendations for further analysis
